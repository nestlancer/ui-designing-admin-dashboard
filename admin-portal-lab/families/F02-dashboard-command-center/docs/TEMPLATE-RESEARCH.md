## V1–V5 pattern map
- **V1 Northstar:** Tabler structure + Carbon honest data states, one high-contrast verdict.
- **V2 The Brief:** finance editorial rhythm + decision-first inverse pyramid, no invented live digest.
- **V3 Queue spine:** Linear-style compact row navigation + finance progressive disclosure; labelled queue previews.
- **V4 Signal board:** Grafana-style overview / service subdivision + sectioned console; all uncertain statuses remain `not checked`.
- **V5 Ledger:** Stripe-style tabular figures + restrained compact Tabler density.

All patterns are checked against the API map and report. **No features invented from templates; all CTAs are Gate-A-backed routes or explicitly labelled demo-only.** None of these external pages or images is loaded by the prototypes.

**Gate T: PASS** — 4 queries, 10 sources opened, patterns mapped to all 5; S → R → A → T order respected.

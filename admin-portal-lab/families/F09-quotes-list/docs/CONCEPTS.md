# F09 concepts

1. V1 **Revenue watchtower** — grounded captured table with explicit active-total context.
2. V2 **Aging queue** — follow-up age is emphasized as the queue ordering cue.
3. V3 **Revenue cards** — card dossiers for task-oriented row scanning, same data fields.
4. V4 **Ledger** — denser financial register and compact filters.

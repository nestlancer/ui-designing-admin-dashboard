2. **Evidence explorer** — audit-led, query and table first; webhooks secondary in a separate workspace; compact investigation spine.
3. **Connections map** — integration-led flow, endpoint creation at the center; audit as verification workspace.

5. **Trace journey** — editorial hierarchy with a sequenced trace narrative and gentle reduced-motion-aware transitions.

All share teal; differences should be geometry, navigation, content hierarchy and density rather than colour alone. Execution must be assessed against this intent; do not mark Difference PASS based on cards alone.
